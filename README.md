# 🐍 Python Öğrenme Yolculuğum

Bu depo, Python öğrenme sürecimde yazdığım kodları, çözdüğüm algoritmaları ve pratiklerimi içermektedir. 

## 📂 İçerik
* **Error Handling:** `try-except` blokları ile hata yakalama.
* **List Comprehension & Built-in Functions:** `map`, `filter`, `lambda`, `any`, `all` kullanımları ve tek satırlık veri işlemleri.
* **Numpy:** Vektörel işlemler ve array (dizi) kullanımlarına giriş.

## 🚀 Hedefim
Sıfırdan ileri seviyeye kadar tüm Python temellerini sağlam bir şekilde oturtmak ve veri bilimi/algoritma mantığını kavramak.
